# Arena 榜单

本次修改涉及 geese（展示）、pangu（接口）和 Sand（采集）。

## 部署顺序

1. 暂停榜单采集，尚未执行初次迁移的库先执行 pangu 的 `doc/20260920_arena_rank.sql`，为现有两张榜单表增加可空字段，并保留原始榜单分数的小数。已执行的库不要重复运行该脚本。
2. 部署 Sand 和 pangu，并重启后端进程。已有库若包含停用的 `sessions`、`release_date`、`logo` 列，执行 pangu 的 `doc/20260930_cleanup_arena_columns.sql`；若仍含 `unit_price`，先备份该列及 `price_unit`，再执行独立的 `doc/20260930_drop_arena_unit_price.sql`。新脚本保留输入／输出金额，仅修正旧计价标记并删除 `unit_price`，不要重复执行已完成的清理。在 Sand 目录重新运行 `python rank_main.py lmarena`。相同发布日期也会更新元数据；历史月份缺失的价格不会伪造补齐。
3. 部署 geese。仅部署前端时，旧接口没有的新字段会显示“暂无”或“—”。

## 数据与展示

- 支持 `text`、`webdev`、`vision`、`text-to-image`、`text-to-video` 五类，默认 `text`；`webdev` 保留接口参数，界面显示“编码 / Coding”。旧接口返回的其他分类不会显示，缺失或不支持的 URL 分类参数回退到 `text`。
- `model_id` 使用 Arena 的完整公开名称 `modelDisplayName`，保留日期、preview 和配置后缀；`modelKey` 可能是匿名测试代号，仅作为历史快照标识，不再作为榜单公开 ID。公开榜单标识不保证等于各厂商的 API 参数，不能靠去掉括号或后缀推测 API ID。
- 榜单使用 `votes` 和 Arena 分数。票数满 1000 以小写 `k` 缩写，最多一位小数且不保留末尾 `.0`，例如 `13320 → 13.3k`、`1000 → 1k`；不足 1000 显示原数，缺失或无效显示 `—`，悬停可看完整票数。
- 每个模型占一条紧凑的表格行，收起时各列内容垂直居中。展开行使用上下两层：模型名称、分数、票数和价格在第一层对齐，厂商与完整 `model_id` 在第二层对齐；排名和模型图标在整行居中，行高和列宽保持不变。名称超长时省略；ID 使用次要文字色、保持单行且不截断，超出表格可视范围时通过表格原有的横向滚动查看。一次只展开一个模型，点击其他模型自动收起之前的；再次点击当前模型可收起，切换分类或月份时重置展开状态。不显示推出时间。模型图标使用本地供应商映射；未知供应商或加载失败时显示首字母。
- 展开的 ID 左侧提供复制图标，悬停及屏幕阅读器可获知“复制模型 ID”，长 ID 不会把复制按钮推到右侧屏幕之外。只复制完整原始 `model_id`，并通过现有消息组件提示成功或失败；复制后保持当前模型展开，失败时仍可手动选择复制。
- Arena logo 随应用主题反色；供应商图标保持品牌色，并使用白色底板。
- 模型名称下显示厂商；仅开源模型追加“· 开源”。`Proprietary`、`Unknown`（忽略大小写）及缺失、空白许可不显示标签或分隔点。
- 价格表头统一为“价格 / Price”，仅展示 `input_price` / `output_price` 的 token 价格，例如 `$10 / 50`，只保留开头的 `$` 符号，斜线两侧各留一个空格；不显示“美元 / USD”、“输入 / 输出”或“每百万”文案。单边缺价保留 `—`，例如 `$10 / —`。
- `input_price` / `output_price` 仍表示每百万 token 的美元价格，由 `price_unit=usd_per_million_tokens` 标明计价基准。移除 `unit_price` 后，图片和视频没有有效 token 价格时显示“暂无”，不把按张或按秒价格挪入输入、输出价格。
- 价格列先显示稍大的等宽数字金额，后跟小号圆角档位标签；金额与标签保持同排，金额保留完整精度。窄屏通过表格横向滚动查看，悬停金额可查看输入／输出含义。
- 价格档位从低到高为“便宜、适中、贵、很贵”（英文 Affordable、Moderate、Expensive、Very expensive），对应后端 `low`、`medium`、`high`、`very_high`。
- `price_tier` 由后端计算，仅使用所选月份、当前分类排名前 20 的模型，以完整有效的输入价加输出价比较；缺失价格不参与，也不会补入第 21 名之后的模型。按相同计费单位计算 25%、50%、75% 分位数（inclusive）：小于等于三个分界点时依次为便宜、适中、贵，超过第三个分界点为很贵。同价同档，零价有效且为便宜；不足 20 个模型时使用实际数据，价格重复或样本过少时部分档位可能为空。

## 验证

- geese：TypeScript、修改文件 ESLint、`ArenaModel.test.tsx` 和 `LMRankPage.test.tsx`，覆盖模型展示、价格缺失和精度、票数格式边界、旧接口分类过滤和默认分类。
- pangu：`src/tests/test_lm_rank.py`，覆盖当前分类前 20 的价格分档、四分位边界、同价、零价/缺失价、分类校验与历史空榜。
- Sand：`tests/test_arena_data.py` 和 `tests/test_arena_storage.py`，使用官方结构化样本与 SQLite 内存数据库。
- 浏览器使用本地测试 API 验证桌面/手机、中英文、浅色/深色、展开详情、视频费用与缺月空状态；没有连接或写入线上数据库。
